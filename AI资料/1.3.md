# OpenClaw

## 1.名词解释

在使用OpenClaw 之前，我们需要先搞懂这些核心概念，他们是正整个框架的基础，也是配置和排错的关键。

| 名词              | 通俗解释               | 核心作用                                                     |
| ----------------- | ---------------------- | ------------------------------------------------------------ |
| 大预言模型（LLM） | 智能体“思考大脑”       | 负责理解你的需求，推理逻辑，生成回复，比如 DeepSeek,豆包，GPT都是大模型 |
| Skill(技能)       | 智能体的“手脚/工具箱”  | 扩展插件，每个技能封装了一项具体的执行能力，比如 文件读写，命令行执行，网页搜索，代码运行，让AI能真正的“动手做事” |
| AI Agent(智能体)  | 你的专属数字员工       | 接收你的指令，调用大模型思考，调度技能执行任务，是整个系统的“大脑+执行者” |
| Gateway（网关）   | 整个系统“中央调用中枢” | OpenClaw的核心后台服务，24小时运行，负责接受用户请求，权限校验，消息路由，任务调度，默认监听 18789端口 |
| API-KEYS          | 大模型的身份凭证       | 调用大模型API的身份秘钥，用来验证你的身份，控制API调用权限，比如你配置的豆包API秘钥，不要泄露给他人 |
| Token             | 身份凭证               | OpenClaw 的访问令牌，用来验证你访问网关的身份，避免未授权访问。 |
| Tokens            | 计算单位               | 大模型的计算单位，是大模型处理文本的最小单位。针对目前主流的大模型（如GPT系列，豆包，通义千问等），由于不同模型的分词器（Tokenizer）存在差异，没有绝对统一的标准，通常1个字符就是1个Tokens, 但有时“我们”这两个字符会被合并为1个tokens |

## 2. OpenClaw的不同版本

OpenClaw 分为GitHub的原版和Gitee的中国社区版，另外国内还衍生出了各种不同的版本。ArkClaw，QClaw, JVS Claw,DuClaw,小艺 Claw，LinClaw

| 版本名      | 维护团队     | 核心特点                                                     | 适合人群                                                 |
| ----------- | ------------ | ------------------------------------------------------------ | -------------------------------------------------------- |
| OpenClaw    | 海外官方团队 | 部署方式，本地源码部署，依赖Node.js/WSL 环境<br />功能： 原生功能最全，全球社区生态最丰富<br />适配模型：以GPT，Claude等海外大模型为主<br />生态：海外工具生态，国内网络适配差，访问速度比较慢 | 海外开发者，有海外网络环境的极客用户                     |
| OpenClaw-CN | 国内开源社区 | 部署方式，本地源码部署，依赖Node.js/WSL 环境<br />功能：网络加速，实时同步官方更新，原生支持飞书、钉钉、企业微信、QQ等国内通讯平台<br />适配模型：原生支持DeepSeek等国产大模型，也兼容海外模型<br />生态：适配国内开发环境，优化依赖包下载速度，解决原版网络问题 | 国内开发者，想要本地化原版体验的技术用户，是开发者的首选 |
| ArkClaw     | 字节火山引擎 | 部署方式：2分钟极速部署，无需本地环境配置，远端Saas，开箱即用<br />功能：深度整合飞书<br />适配模型：豆包、火山方舟系列模型、兼容Claude<br />生态：支持飞书文档/日程/群聊联动 | 飞书重度用户、企业团队、零基础小白                       |
| QClaw       | 腾讯         | 部署方式：本地轻量部署/云端Saas<br />功能：微信/QQ 原生直连，零配置远程操作，上手简单<br />适配模型：混元大模型，兼容海外主流模型<br />生态：微信/QQ 生态深度打通，内置5000+第三方技能生态 | 微信生态用户，日常办公协作用户                           |
| JVS Claw    | 阿里云       | 部署方式：本地轻量部署/云端托管/移动端<br />功能：支持移动端使用，团队多智能体协作能力强<br />适配模型：通义千问系列的国产大模型<br />生态：钉钉，企业微信深度整合，适配国内的办公场景。 | 钉钉用户，移动端高频使用者，中小团队                     |
| LinClaw     | 七牛云       | 部署方式：云端托管<br />功能：大文件处理专项优化，云存储能力突出<br />适配模型：兼容主流国产大模型/海外大模型<br />生态：七牛云存储生态，大文件传输/处理优化。 | 有大文件处理需求的用户、开发者                           |

### 注意事项

​	不要在自己常用的电脑上或手机上部署OpenClaw，因为OpenClaw依赖于其他大模型，如果大模型在查询网站时，网站经过了SEO污染，大模型的输出结果就会被污染，污染的结果被OpenClaw执行后，会导致电脑出现不可预测风险（如：系统被删除、重要文件联通备份都被删除，产生不可预测的金融问题等）。

​	在虚拟机上使用OpenClaw，沙盘封箱中的任何操作都不会影响真实系统，且可以通过快照恢复OpenClaw 的状态。

# 4. 安装 OpenClaw

海外原版官网：https://openclaw.ai

## 4.1 One-liner

+ Windows:

```
powershell -c "irm https://openclaw.ai/install.ps1 | iex"
```

+ Mac&Linux:

```
curl -fsSL https://openclaw.ai/install.sh | bash
```

## 4.2 Npm & yarn & pnpm

```
# Install OpenClaw  安装命令
$
npm i -g openclaw@latest   # 全局依赖
npm install -g openclaw # 全局依赖
yarn add global openclaw # 全局依赖
pnpm add -g openclaw  # 全局依赖

# Uninstall OpenClaw   卸载命令
npm uninstall -g openclaw@latest
yarn remove global openclaw
pnpm remove -g openclaw@latest




# Meet your lobster
$
openclaw onboard
```
