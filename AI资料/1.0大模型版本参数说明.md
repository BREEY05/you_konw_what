# 大模型版本参数说明

# 1. 核心版本区分

+ qwen3.6:lastest /qwen3.6:27b /qwen3.6:35b 

  基础通用版：27b (270亿参数)、 支持文本+图像 多模态输入、上下文窗口 均为256k

+ -coding 后缀版本

  代码专用优化版：针对代码生成、调试、解释做了专项优化，适合编程开发场景

+ -a3b/ -27b 标识

  代表不同模型架构/参数规模, 27b 为轻量高效性，35b为更强推理能力型。



# 2. 精度格式说明

+ mxfp8  /bf16/nvfp4

  不同量化精度：bf16(原生精度，效果最好，体积大)、mxfp8（8bit 量话,平衡性能和显存）、nvfp4（4bit量化，体积最小，显存占用最低）

+ MLX 标识

  专为 Apple Silicon（M系列芯片）优化的部署版本，适配Mac 本地运行。

# 3. 显存/存储占用（Size）

+ 所有模型上下文同意为256k tokens ,支持超长文本处理。
